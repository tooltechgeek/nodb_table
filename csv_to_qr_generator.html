CSV → QR codes

Offline CSV-to-QR utility. Each row becomes a URL with Base64URL-encoded JSON in its #data= fragment.

Choose a CSV file with an id column.

CSV parsing, JSON encoding, Base64URL encoding and file downloads run locally in this browser. No file is uploaded.

Before printing on label stock, print a test sheet on ordinary paper at 100% scale and check alignment.
